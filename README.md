### 🧭 我在做什么

我关注 **AI Agent 的工程化落地**：从任务编排、工具调用与模型路由，到质量审核、失败恢复和自动化交付。也在探索 AI 如何帮助内容创作、日常开发和复杂系统治理。

- 🤖 **构建 Agent 运行时**：多模型接入、工具系统、任务编排、追踪与治理。
- 🎬 **把创作变成流程**：让故事从构思、审核、生产到交付可验证、可恢复。
- 🛠️ **改善 AI Coding 工作流**：最小充分改动、自动化校验、结果可追溯。
